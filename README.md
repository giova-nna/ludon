# Ludon - seus jogos, seu controle

(adicionar foto da página inicial aqui futuramente)

Projeto criado para o projeto final da matéria de Programação Web, do segundo semestre da graduação em Análise e Desenvolvimento de Sistemas.

__Ludon__ é um site de tracking de progresso em jogos, inspirado em sites como _Backloggd_ e _Your Gamer Profile_.

## Elementos principais: 

- Utilização da API do IGDB para buscar jogos.
- Interface personalizável, podendo escolher entre modo claro e escuro e a cor principal da interface.
- Controle de dados feito através do `localStorage`.

> O projeto usa apenas HTML, CSS e JavaScript.

### Feito do zero, sem uso de inteligência artificial.
