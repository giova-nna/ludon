# Ludon - seus jogos, seu controle

(adicionar foto da página inicial aqui futuramente)

Projeto criado para o trabalho final da disciplina de Programação Web, do segundo semestre da graduação em Análise e Desenvolvimento de Sistemas.

__Ludon__ é um site de tracking de progresso em jogos, inspirado em sites como _Backloggd_ e _Your Gamer Profile_.

## Elementos principais: 

- Interface personalizável, podendo alterar a cor principal da interface.
- Controle de dados feito através do `localStorage`.

> O projeto usa apenas HTML, CSS e JavaScript.
